# Homebrew tap for Shrinkbox

[Shrinkbox](https://github.com/Arrows78/Shrinkbox) makes images, videos, audio files and PDFs smaller on macOS: drop them, copy them, or let a folder do it.

## Install

```bash
brew install arrows78/shrinkbox/shrinkbox
```

Use the full name above. Homebrew 7 only loads casks from third-party taps you trust, and naming the tap in the command trusts that cask. If you ran `brew tap arrows78/shrinkbox` first, trust the tap before installing:

```bash
brew trust --tap arrows78/shrinkbox
brew install --cask shrinkbox
```

Update with `brew upgrade --cask shrinkbox`. The command line is linked as `shrinkbox`.

## First launch

Shrinkbox is signed ad hoc and not notarized, so macOS blocks the first launch. Open **System Settings › Privacy & Security** and click **Open Anyway**, or run:

```bash
xattr -dr com.apple.quarantine /Applications/Shrinkbox.app
```

## Uninstall

```bash
brew uninstall --cask shrinkbox         # keeps your settings
brew uninstall --zap --cask shrinkbox   # also removes Shrinkbox's settings
```

Your own files are never removed.

## About this repository

`Casks/shrinkbox.rb` is generated by the release workflow of the [Shrinkbox repository](https://github.com/Arrows78/Shrinkbox) on every release. Do not edit it by hand.
